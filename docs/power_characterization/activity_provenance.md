occupancy describe only the directed test, not a physical measurement window
or expected deployment profile.

## Reproduction and integrity

From the repository root, run:

```sh
bash sim/scripts/run_ipm_state_workload.sh
```

The testbench checks the state and enable outputs on every cycle and asserts
the expected sample count per state. The Python analyzer independently
checks trace columns, cycle continuity, state/output correspondence,
transition sequence, and expected state counts. Simulator/tool version and
execution outcome should be captured in the phase report when rerun. Any new
activity trace for power work must include a full-design scope, matching RTL
revision, workload, clocks, period, voltage/corner, parasitic source,
measurement interval, and annotation coverage before power is calculated.
